Student Learning API

Try the API

Learn how APIs work

This is a free practice API for students aged 11–15. You can call these endpoints with JavaScript fetch() from your own HTML projects — even from Live Server on your computer.

Important: All student data is fictional. It was invented for learning and does not describe real people.

Key ideas

Before you start coding, learn these five words.

Request

A message you send to the API asking for data. Example: “Give me a random fact.”

Response

The answer the API sends back. It usually contains JSON data.

Endpoint

A specific URL that does one job, like /api/fact or /api/jokes.

JSON

A text format for data that looks like JavaScript objects. APIs love JSON!

Status code

A number that tells you if the request worked. 200 = OK, 404 = not found, 400 = bad request.

All endpoints

Replace the base URL with your deployed Vercel URL after you publish the project.

GET /api/hello

A friendly welcome message from the teacher.

Example: /api/hello

GET /api/fact

Returns one random educational fact. Optional: filter by category.

Examples: /api/fact · /api/fact?category=space

Categories: animals, computers, science, space, geography, programming

GET /api/students

Returns fictional students. Filter by city, level, or language.

Examples: /api/students · /api/students?city=Tangier&level=Beginner

GET /api/student

Returns one student by ID.

Example: /api/student?id=2

GET /api/jokes

Returns one random child-friendly tech joke, or all jokes.

Examples: /api/jokes · /api/jokes?all=true

GET /api/weather

Fictional weather for Moroccan cities (practice only).

Examples: /api/weather · /api/weather?city=Tangier

GET /api/health

Checks if the API is online and returns the current time.

Example: /api/health

How to use fetch()

Copy these examples into your own HTML <script> tags. After deploying, replace the URL with your Vercel link.

Using .then()

fetch("/api/fact")
  .then(response => response.json())
  .then(data => {
    console.log(data);
  })
  .catch(error => {
    console.error(error);
  });

Using async/await

async function getJoke() {
  try {
    const response = await fetch("/api/jokes");
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.error(error);
  }
}

getJoke();

From your own HTML project (after deploy)

fetch("https://YOUR-PROJECT.vercel.app/api/students?city=Tangier")
  .then(response => response.json())
  .then(data => {
    console.log(data.count);
    console.log(data.data);
  });
